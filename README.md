# Hey Chef! — Android

**[⬇ heychef.apk](https://github.com/zuzenka/heychef-android/releases/latest/download/heychef.apk)** — always the latest version.

This repository only holds the app's releases; the source code is private. Once installed, the app offers new versions itself.

## Установка (один раз)

1. Откройте ссылку выше на телефоне и скачайте `heychef.apk`.
2. Откройте файл. Если телефон спросит, разрешите установку из этого источника (браузера или «Файлов»).
3. Если Play Защита предложит проверить приложение, нажмите «Проверить». Если появится «Заблокировано» — «Подробнее» → «Всё равно установить».

Дальше обновления приходят прямо в приложение: «Вышла версия … → Обновить».

## Installing (once)

1. Open the link above on the phone and download `heychef.apk`.
2. Open the file. If the phone asks, allow installing from this source (the browser or Files).
3. If Play Protect offers to scan the app, tap Scan. If it says the app was blocked — More details → Install anyway.

After that, updates come inside the app: "Version … is out → Update".

## Namestitev (enkrat)

1. Na telefonu odprite zgornjo povezavo in prenesite `heychef.apk`.
2. Odprite datoteko. Če telefon vpraša, dovolite nameščanje iz tega vira (brskalnik ali Datoteke).
3. Če Play Protect ponudi pregled aplikacije, tapnite Preglej. Če piše, da je blokirana — Več podrobnosti → Vseeno namesti.

Nato posodobitve pridejo v aplikaciji: »Na voljo je različica … → Posodobi«.
